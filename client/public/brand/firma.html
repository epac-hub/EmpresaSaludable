Firma de correo Empresa Saludable

Dos firmas listas para Gmail, Outlook y Apple Mail. El logo se carga desde www.empresasaludable.net, por lo que se ve igual en todos los dispositivos sin adjuntar archivos. Complete sus datos, pulse «Copiar firma» y péguela en la configuración de firmas de su correo.

1

Firma personal

Saludos cordiales,

Se copia con formato. En Gmail: Configuración → Ver todos los ajustes → Firma → Crear nueva → pegar.

2

Firma corporativa (buzón hello@)

El código HTML sirve para Outlook de escritorio, plataformas de correo masivo o para que un administrador la asigne a todo el equipo.

Instalación

Dónde pegarla

  1. Gmail (web): rueda dentada → «Ver todos los ajustes» → pestaña «General» → «Firma» → «Crear nueva» → pegue con Ctrl+V / ⌘V → «Guardar cambios».
  2. Outlook (web y nuevo Outlook): Configuración → Cuentas → Firmas → «Nueva firma» → pegue → Guardar.
  3. Apple Mail: Mail → Ajustes → Firmas → «+» → pegue. Desmarque «Usar siempre mi tipo de letra predeterminado».
  4. Móvil: la app de Gmail solo admite texto; use la firma desde la web para que aplique en escritorio y deje en el móvil «Empresa Saludable · www.empresasaludable.net».
